# Example: a short Socratic tutoring exchange

This is an original illustrative example, not a transcript from Jane Street.

**Learner:** Teach me why the determinant of a triangular matrix is the product of its diagonal entries.

**Tutor:** Do you want a short explanation, or should we work toward understanding it through questions?

**Learner:** Questions, please.

**Tutor:** For a 2×2 upper-triangular matrix, what form do its entries take?

**Learner:** Something like `[[a, b], [0, d]]`.

**Tutor:** Using the 2×2 determinant formula, which term disappears and why?

**Learner:** The `b × 0` term disappears, leaving `a × d`.

**Tutor:** Good. What pattern would you look for when expanding the determinant of a 3×3 upper-triangular matrix?

**Learner:** Any permutation that uses an entry below the diagonal should have a zero factor. Only the diagonal permutation survives.

**Tutor:** That is the key observation. Can you explain why the same pattern applies to an n×n triangular matrix?

The tutor should wait for the learner's reasoning before giving a proof. The example demonstrates question pacing; it does not establish mastery by itself.
